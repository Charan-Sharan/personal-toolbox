# Personal Toolbox

A lightweight collection of useful browser tools. Includes a searchable homepage and the EMI & Prepayment Calculator. Plain HTML, CSS and JavaScript: no installation, build step, external libraries, or backend.

## Publish with GitHub Pages

1. Create a **public** GitHub repository named **personal-toolbox**. The free GitHub Pages option requires a public repository.
2. Extract the ZIP on your computer. Open the extracted folder.
3. In the GitHub repository, choose **Add file → Upload files**. Upload the extracted contents, keeping the `tools` folder. **Do not upload the ZIP itself or an extra enclosing folder.** `index.html` must appear at the repository root.
4. Commit the uploaded files to `main`.
5. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then **Save**.
6. Wait for deployment to finish. The Pages screen will show the actual website address. Normally it is `https://YOUR-USERNAME.github.io/personal-toolbox/`.
7. Bookmark that address on your computer and phone.

If your file picker does not select folders, drag the `tools` folder and the root files into GitHub's upload area from your file manager. Confirm the calculator appears at `tools/loan-emi-calculator.html` before committing.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Update an existing tool

Replace its file at the **same path** and commit to `main`. GitHub Pages republishes automatically; existing bookmarks continue working. For small changes, open the file on GitHub, choose the pencil icon, edit and commit. For a replacement generated by ChatGPT, upload it into the matching folder using the same filename. Verify the deployment succeeds before checking the live page; refresh if your browser is showing an older copy.

For the EMI calculator, the path is `tools/loan-emi-calculator.html`. Keep the “Personal Toolbox” link near the top when replacing it, or add this after the opening `<body>` tag:

```html
<nav aria-label="Toolbox navigation"><a href="../index.html">← Personal Toolbox</a></nav>
```

## Add another tool

1. Save a self-contained HTML file in `tools/`, for example `tools/unit-converter.html`.
2. Add an entry to the array in `tools.js` (put a comma between entries):

```javascript
{
  id: "unit-converter",
  title: "Unit Converter",
  category: "Everyday",
  description: "Convert measurements quickly.",
  href: "tools/unit-converter.html",
  keywords: "length weight temperature conversion"
}
```

3. Commit both changes to `main`. The homepage automatically shows the new card and category.

Use simple filenames with letters, numbers, hyphens or underscores. This catalog supports single-file HTML tools directly inside `tools/`. Use relative links; a link beginning with `/` would point outside the project on GitHub Pages.

## Files

- `index.html`: homepage.
- `styles.css`: homepage styling.
- `tools.js`: tool catalog; edit this when adding or removing tools.
- `app.js`: homepage search and category filtering.
- `favicon.svg`: site icon.
- `tools/loan-emi-calculator.html`: standalone loan calculator, including a link back to the homepage.
- `tools/gold-loan-calculator.html`: gold collateral and repayment estimator. Enter current lender valuation, LTV, rate and charges; it does not use live bank quotes.

## Open offline

Keep the folder structure intact and open `index.html` in a browser. No server is required. The calculator can also be opened directly.

## Your data

The website and source code are public when hosted this way. The calculator does not send your entered loan details to a server. Optional saved plans are browser/device-local and do not sync between devices. Use the calculator's JSON export/import for backup or transfer. Do not upload personal plan exports into the public repository.

The calculator estimates monthly reducing-balance loans, including zero interest, actual EMI overrides, monthly/annual extras, dated lump sums, rate changes and separate fees/taxes. Dated extras apply after the first EMI on or after their date. It does not model daily interest, missed payments, moratorium, staged disbursements or flat-rate loans. Loan categories are labels; enter your own lender's terms.

The gold-loan estimator converts entered net gold weights and karat purities into an indicative value, applies a user-entered LTV cap, and estimates EMI, monthly-interest bullet, rear-ended bullet, front-ended interest bullet, or a simplified overdraft cash flow. Bank rates, appraised weight/value, fees, interest conventions and actual approval terms must be confirmed with the lender. It is not an official SBI, HDFC Bank or ICICI Bank quotation or eligibility decision.
